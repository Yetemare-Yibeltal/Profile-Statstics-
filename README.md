# Profile Statistics Dashboard

An enterprise-ready, modular JavaScript dashboard for tracking developer profile analytics, metric distribution, and traffic patterns. Built completely from scratch using modern ES Modules, CSS design tokens, and clean UI architecture.

## 🚀 Features

- **Modular Architecture**: Separate directories for components, data sources, state management, and views.
- **Client-Side Routing**: Fast view navigation without external frameworks.
- **Theme Switching**: Built-in dark and light theme engine using CSS variables and local storage persistence.
- **Lightweight Data Visualizations**: Custom SVG chart components and reactive metric cards.

## 🛠️ Tech Stack

- **HTML5**: Semantic document layout
- **CSS3**: Variables, Flexbox, and CSS Grid
- **JavaScript**: ES6+ Modules without third-party framework dependencies
